# Gemini CLI Communication Protocol Analysis

## 1. Conclusion

The gemini-cli tool uses the **Server-Sent Events (SSE)** protocol for streaming communication with the remote model.

This is achieved by making an HTTP POST request to the API endpoint with the `alt=sse` query parameter. The client then parses the resulting event stream, processing data chunks as they arrive.

---

## 2. Relevant Source Code

The core logic for handling streaming requests is located in the `requestStreamingPost` method within `packages/core/src/code_assist/server.ts`.

**File Path:** `packages/core/src/code_assist/server.ts`

### Snippet 1: Requesting the SSE Stream

This part of the code explicitly sets the `alt=sse` parameter in the request, which instructs the server to send back an event stream.

(Lines 213-226)
```typescript
  async requestStreamingPost<T>(
    method: string,
    req: object,
    signal?: AbortSignal,
  ): Promise<AsyncGenerator<T>> {
    const res = await this.client.request({
      url: this.getMethodUrl(method),
      method: 'POST',
      params: {
        alt: 'sse', // <<< THIS LINE REQUESTS SSE
      },
      headers: {
        'Content-Type': 'application/json',
        ...this.httpOptions.headers,
      },
      responseType: 'stream',
      body: JSON.stringify(req),
      signal,
    });
```

### Snippet 2: Parsing the SSE Stream

This section reads the incoming stream line by line using Node.js's `readline` module. It handles the SSE message format, where data lines are prefixed with `data: ` and messages are separated by blank lines.

(Lines 259-274)
```typescript
      const rl = readline.createInterface({
        input: nodeStream,
        crlfDelay: Infinity, // Recognizes '\r\n' and '\n' as line breaks
      });

      let bufferedLines: string[] = [];
      for await (const line of rl) {
        // blank lines are used to separate JSON objects in the stream
        if (line === '') {
          if (bufferedLines.length === 0) {
            continue; // no data to yield
          }
          yield JSON.parse(bufferedLines.join('\n')) as T;
          bufferedLines = []; // Reset the buffer after yielding
        } else if (line.startsWith('data: ')) {
          bufferedLines.push(line.slice(6).trim());
        } else {
          throw new Error(`Unexpected line format in response: ${line}`);
        }
      }
```
